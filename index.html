Introduction to the Finite Element Method

This short course introduces the finite element method through the Poisson equation, starting from the weak formulation and Galerkin approximation and progressively showing how a mesh is used to construct the approximation space.

2 Notation conventions

The following notation is used throughout the course.

2.1 Domain and mesh

The computational domain is denoted by

\[ \Omega. \]

Its finite-element mesh is

\[ \mathcal T_h, \]

where \(h\) denotes the characteristic mesh size.

A generic finite element is denoted by

\[ T\in\mathcal T_h. \]

For triangular meshes,

\[ h_T=\operatorname{diam}(T), \qquad h=\max_{T\in\mathcal T_h}h_T. \]

2.2 Function spaces

The space of admissible functions satisfying the prescribed Dirichlet values \(g\) is denoted by

\[ V_g = \left\{ v\in H^1(\Omega): v=g \text{ on }\Gamma_D \right\}. \]

The corresponding homogeneous space is

\[ V_0 = \left\{ v\in H^1(\Omega): v=0 \text{ on }\Gamma_D \right\}. \]

Their finite-element counterparts are denoted by

\[ V_{h,g}\subset V_g, \qquad V_{h,0}\subset V_0. \]

The finite-element solution and test functions therefore satisfy

\[ u_h\in V_{h,g}, \qquad v_h\in V_{h,0}. \]

2.3 Global and local basis functions

Global finite-element basis functions are denoted by

\[ \phi_i, \]

where \(i,j,\ldots\) are global degree-of-freedom indices.

The global finite-element approximation is written as

\[ u_h = \sum_i U_i\phi_i. \]

On one element \(T\), local shape functions are denoted by

\[ N_a, \]

where \(a,b,\ldots\) are local element indices.

For a \(P_1\) triangular element,

\[ a,b\in\{1,2,3\}. \]

If the local nodes \(a=1,2,3\) correspond to the global degrees of freedom

\[ i_1,\ i_2,\ i_3, \]

then

\[ u_h|_T = \sum_{a=1}^3 U_{i_a}N_a. \]

2.4 Element and global matrices

Element quantities are identified by the superscript \((T)\).

The elemental stiffness matrix is

\[ K^{(T)}_{ab} = \int_T \nabla N_a\cdot\nabla N_b\,d\Omega. \]

The elemental load vector is

\[ F^{(T)}_a = \int_T fN_a\,d\Omega \]

with additional boundary contributions when non-zero Neumann conditions are present.

Global quantities use global indices:

\[ K_{ij} = \int_\Omega \nabla\phi_i\cdot\nabla\phi_j\,d\Omega, \]

and

\[ F_i. \]

Assembly is expressed as

\[ \boxed{ K_{i_a i_b} \; += \; K^{(T)}_{ab} } \]

and

\[ \boxed{ F_{i_a} \; += \; F^{(T)}_a. } \]

2.5 Algebraic unknowns and Dirichlet conditions

The vector of all nodal values is denoted by

\[ U. \]

Degrees of freedom are separated into free and prescribed Dirichlet values:

\[ U_f, \qquad U_D. \]

After assembly, the corresponding block decomposition of the global matrix is

\[ \begin{pmatrix} K_{ff} & K_{fD}\\ K_{Df} & K_{DD} \end{pmatrix}. \]

The equations associated with the free degrees of freedom are

\[ \boxed{ K_{ff}U_f = F_f-K_{fD}U_D. } \]

2.6 Weak formulation

For the Poisson problem, the bilinear form is

\[ a(u,v) = \int_\Omega \nabla u\cdot\nabla v\,d\Omega, \]

and the linear form is denoted by

\[ \ell(v). \]

The discrete Galerkin problem is

\[ \boxed{ \text{Find }u_h\in V_{h,g} \text{ such that } a(u_h,v_h)=\ell(v_h) \quad \forall v_h\in V_{h,0}. } \]

2.7 Interpolation and error

The nodal finite-element interpolant of a function \(u\) is denoted by

\[ I_hu. \]

It is defined by

\[ I_hu(\mathbf x_i) = u(\mathbf x_i). \]

The \(L^2\) norm is

\[ \|v\|_{L^2(\Omega)} = \left( \int_\Omega v^2\,d\Omega \right)^{1/2}, \]

and the \(H^1\) seminorm is

\[ |v|_{H^1(\Omega)} = \left( \int_\Omega |\nabla v|^2\,d\Omega \right)^{1/2}. \]

For the Poisson problem, this is also the energy norm:

\[ \|v\|_a = |v|_{H^1(\Omega)}. \]
